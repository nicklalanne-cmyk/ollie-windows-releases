# Ollie for Windows

Ollie is the voice-first assistant for ONE Luxury staff and contractors. This is the Windows desktop app.

**[Download the latest installer](https://github.com/nicklalanne-cmyk/ollie-windows-releases/releases/latest)**
(the `.exe` under Assets).

- Runs on Windows 10 and 11 (64-bit, x64).
- Sign in with your Ollie account.
- The app updates itself: when a new version is ready it shows a Restart bar.

Help: [IT@oneluxuryint.com](mailto:IT@oneluxuryint.com)

This repository holds only release files (the installer and its update files). It contains no source code.
